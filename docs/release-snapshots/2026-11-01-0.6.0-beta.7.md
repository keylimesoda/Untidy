# Untidy 0.6.0 beta 7 — 2026-11-01

Beta 7 is the first release cut under the Wear OS UX optimization program
(`.omp/skills/wear-ux-optimizer`, `docs/ux/`). Every change is a
finding-backed experiment with device evidence — see `docs/ux/experiments.md`.

## Highlights

- Sign-in honesty on the watch: entering the code no longer requires babysitting
  the screen. The watch shows a "Waiting — updates once you enter the code"
  state and completes pairing the moment TIDAL approves (EXP-001), and device
  polling now backs off progressively on server `slow_down` instead of hammering
  (EXP-002).
- Dead sessions no longer strand you: when TIDAL rejects the refresh token
  (revoked or aged out), the app clears the session and immediately presents a
  fresh device code instead of retrying broken content panes forever (EXP-008).
- Liked tracks are complete: the Library "Liked tracks" row and list now read
  the full v2 relationships store (server total + batch pages) instead of the
  legacy first-50 endpoint — e.g. a 47-row list becomes the real 264 (EXP-006).
- Like from Track Context: a Now Playing track's context sheet now has the
  Like toggle; the liked state round-trips to the server and the Library row
  (EXP-005).
- Settings truth: account status rows stopped faking tap affordance, and the
  sign-out row wording matches what it actually does (EXP-003, EXP-004/UX-003).

## Install

Install directly on a Wear OS 4+ watch using ADB:

```shell
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:ADB_PORT
adb -s WATCH_IP:ADB_PORT install -r Untidy-orchestrated-0.6.0-beta.7.apk
```

If updating fails with `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, the previous build
was signed with a different debug key: uninstall first (this clears downloads
and the saved session), then install. A fresh install starts at the device-code
sign-in screen.
