# Untidy 0.6.0 beta 8 — 2026-11-01

Beta 8 fixes two audio defects reported on the physical Galaxy Watch6 within
hours of beta.7, both verified end-to-end on that watch. No other behavior
changed relative to beta.7.

## Fixes

- **Silent-but-progressing playback** (UX-021/UX-023): Samsung's compressed
  audio offload path for TIDAL's HE-AAC streams wedges ~10-14 s in on
  `SM-R955U` — the player kept reporting healthy PLAYING while the DSP had
  stopped consuming data, so nothing was ever audible on speaker or A2DP.
  Offload (the battery-optimal path) now stays enabled by default; a stall
  sentinel watches the position/buffer relationship every 2 s, and on proof
  of a dead pipeline it rebuilds the player once onto software decoding and
  persists a per-device suspension, so later tracks start clean. Battery
  first, never silence: healthy devices keep DSP offload; broken ones pay
  the software-decode cost automatically. Verified: one rebuild at T0+48 s,
  then smooth playback; zero false positives in a 110 s control run.
- **"Play on" cannot reach Bluetooth headphones** (UX-022): the picker only
  listed outputs Android had already connected, so bonded-but-disconnected
  headphones were unreachable from the app. The picker now explains the
  constraint and adds "Connect Bluetooth headphones", which opens the
  system media-output switcher (Wear OS 5; falls back to Bluetooth
  settings). Verified on hardware: panel listed AirPods Max + Buds4 Pro,
  connecting flipped the media route to A2DP, and playback followed.

## Verification

## Install

Install directly on a Wear OS 4+ watch using ADB:

```shell
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:ADB_PORT
adb -s WATCH_IP:ADB_PORT install -r Untidy-orchestrated-0.6.0-beta.8.apk
```

If updating fails with `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, the previous build
was signed with a different debug key: uninstall first (this clears downloads
and the saved session), then install. A fresh install starts at the device-code
sign-in screen.
