# Untidy 0.6.0 beta 6 — 2026-09-07

Beta 6 is a stabilization release focused on recovery, offline correctness, and measured playback efficiency on real hardware.

## Highlights

- Replaced the inline audio-output section with a dedicated Wear OS picker listing the watch speaker and connected Bluetooth outputs.
- Closed the remaining navigation dead ends. Back now unwinds the actual browsing path; failed player states offer Home, Retry, and Repair; external player routes no longer get overwritten by startup navigation.
- Preserved search results, pull-up position, and in-progress playlist actions across navigation and ambient transitions.
- Made offline playback genuinely offline: completed downloads persist their authorized DASH descriptor and metadata atomically, replay uses a cache-only data source, and legacy downloads expose an explicit Repair path.
- Added optional Media3 compressed-audio offload with normal playback fallback. It respects the selected quality and requires gapless support rather than silently degrading album playback.
- Kept the quality gem in the pull-up header and retained the refined guarded grip interaction.

## Hardware findings

Validated on a Samsung Galaxy Watch6 LTE (`SM-R955U`). On the watch speaker with the display asleep:

- FLAC software decode used 33.23 CPU-seconds over 180.74 seconds, or 18.39% of one CPU core.
- TIDAL HE-AAC v1 at roughly 96 kbps used the watch's verified compressed-offload path and consumed 1.19 CPU-seconds over 180.29 seconds, or 0.66% of one core.
- The approximately 28× app-CPU reduction is real; the short samples are not long enough to claim a whole-device battery-life percentage.
- The watch advertises offload for MP3, AAC-LC, HE-AAC v1, and HE-AAC v2, but not FLAC. Actual offload remains stream- and route-dependent.

Full fidelity remains opt-in. Untidy requests the user's selected quality and uses hardware offload only when Android accepts that exact stream and route.

## Install

Install directly on a Wear OS 4+ watch using ADB:

```shell
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:ADB_PORT
adb -s WATCH_IP:ADB_PORT install -r Untidy-orchestrated-0.6.0-beta.6-recovery.apk
```

Installing the APK on a phone does not transfer it to the watch. Updating with `-r` preserves app data when the signing key matches.
